Claude Code sessions do not get expensive because the model is verbose. They get expensive because tool output accumulates in the context window and is billed again on every turn that follows. skout keeps it out of the window — and measures the difference, so the claim is auditable rather than asserted.

What it does

01

Blocks re-reads

If a file is already in context and has not changed, the second Read is refused with a pointer to the first one. Dedupe fires only when size and mtime match, and the content hash agrees — a file edited in place is still detected as changed.

02

Blocks unbounded reads

A Read with no offset/limit on a very large file is refused with a cheaper alternative: grep it, or page it.

03

Measures everything

Parses your own transcripts for real token counts at Anthropic's published per-token rates, so every number above came out of the tool itself.

A guard must never be the thing that breaks your session. Every rule has an escape hatch — once a call has been blocked once, it is allowed through, so a genuinely-needed read costs one extra turn and never a deadlock. Every failure path emits nothing at all: a broken skout is an absent skout.

Install

cargo install --git https://github.com/CHIRANTAN1455/skout-cli
skout init

Or build from source:

git clone https://github.com/CHIRANTAN1455/skout-cli
cd skout-cli && cargo build --release
./target/release/skout init

init writes four hooks into ~/.claude/settings.json (backing up the existing file first), creates ~/.skout/config.toml, and installs a /skout slash command. Removal is symmetric — skout uninstall strips only skout's own entries and leaves every other setting untouched.
